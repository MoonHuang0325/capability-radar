# data/ · 结构化信号数据

这里是能力雷达的数据层。Markdown 周报是给人读的输出，这里是给机器、图表和二次加工用的资产。

## 目录

- `signals/` — 单条信号，YAML 格式，一文件一条，格式见 `schemas/signal.schema.json`
- `procurement/` — 中国 AI 招投标记录，CSV，一行一个中标项目

## 证据等级

| 等级 | 含义 |
|---|---|
| A | 一手原始来源，链接可点击核验（官方公告、原始报告） |
| B | 权威二手：官方数据的可靠媒体转述，已注明原始出处 |
| C | 社区信号或未溯源数据，**待核实**，引用前请自行验证 |

规则：找不到原始链接的信号，`confidence` 不得为 A；C 级信号补齐来源后升级。

## 采购数据字段

`procurement/` 每行字段：项目名 / 采购人 / 采购人类型 / 行业 / 省份 / 中标方 / 金额(元) / 公告日期 / 项目类型 / 场景 / 原始公告 URL / 抓取日期 / 证据等级

项目类型枚举：算力 / 平台 / 应用 / 安全治理 / 数据标注 / 咨询

## 当前状态

种子阶段（2026-08-13 起）。已收录经一手来源核验的记录，更多历史记录的溯源补录进行中。欢迎通过 issue 提交新记录（模板内置来源要求）。
