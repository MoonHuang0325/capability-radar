# 有证据的 AI 转型路线图

这不是又一份"AI 学习路径"。每个节点都尽量挂到本仓库的真实信号上，并标注证据等级（A=一手可核验 / B=权威二手 / C=待核实）。没有证据支撑的节点会明确写"待补证据"——路线图的可信度，来自它敢于标出自己的盲区。

证据每周更新，路线图随证据演化。

---

## 🎯 运营 / 市场岗 → AI 应用操盘手

**第一步：从"用 AI"到"搭 AI"**

企业招聘重心已锚定在应用开发层：2026 年 1-4 月新发 AI 岗位中，B 类应用开发岗占 43.8% 居首（A 底层技术 / B 应用开发 / C 使用者的三分法中，"会用"是最不值钱的一层）。
证据：[脉脉岗位结构信号](../data/signals/2026-08-13-maimai-b-class-jobs-share.yml)（B 级）

**第二步：盯住"可衡量 ROI"的落地场景**

约 88% 的 AI 试点从未投产，企业转型进入 ROI 硬约束阶段——能讲清"这个 Agent 每周省多少小时 / 多少钱"的人，比会做 Demo 的人稀缺得多。
证据：[IDC 试点投产率信号](../data/signals/2026-08-13-idc-ai-pilots-not-in-production.yml)（C 级，待一手核实）

**第三步：建立可验证的作品证据链**

公开的项目仓库、可点击核验的产出、持续更新的记录，比简历上的形容词有力得多。本仓库本身就是这个方法的示例。
证据：待补（人才市场对"作品证据"的定价信号，监控中）

## 💼 销售 / 商务岗 → AI 解决方案顾问

**第一步：读懂采购语言**

中标公告是最诚实的转型数据。例：北京银行大模型安全网关项目完成招标，京东科技 98 万中标（预算 200 万，仅限大模型原厂商投标）——读懂预算结构、投标门槛、候选人价差，就是读懂客户的真实决策链。
证据：[北京银行中标公告](../data/signals/2026-08-13-bank-of-beijing-llm-security-gateway.yml)（A 级）、[证据原件存档](../evidence/procurement/2026-07-28-bank-of-beijing-llm-security-gateway.md)

**第二步：押注"低谷期的务实采购"**

Gartner 判定 AI 在 2026 年处于泡沫破灭低谷期，企业偏好向现有供应商采购战术性项目；同时全球 AI 支出预计 2.52 万亿美元（+44%）。低谷期不是没钱，是钱变得更挑——能卖"确定性"的人赢。
证据：[Gartner 支出研判](../data/signals/2026-08-13-gartner-ai-trough-2026.yml)（C 级，待一手核实）

**第三步：从卖产品到卖"避坑"**

失败与成功同权：知道哪些 AI 项目烂尾、为什么烂尾，是客户愿意付费的信息。
证据：待补（烂尾案例结构化采集已列入 [ROADMAP](../ROADMAP.md)）

## 🛠 开发者 → Agent 工程师

**第一步：把工程能力接到 Agent 工作流上**

B 类应用开发岗占新发 AI 岗位 43.8%，企业缺的不是会调 API 的人，是能把 Agent 嵌进真实业务流程的人。
证据：[脉脉岗位结构信号](../data/signals/2026-08-13-maimai-b-class-jobs-share.yml)（B 级）

**第二步：补评估与可观测性**

AI 评估与可观测性是雇主侧最大的供给缺口（连续两期雷达强化信号）——会让 Agent "可度量、可排错"的工程师，议价能力显著更高。
证据：[2026-08-13 期报告](../reports/2026-08-13.md)（综合信号）

**第三步：进入有真实采购预算的行业**

金融、政务的大模型安全与合规采购已进入集采目录，预算真实、流程透明、可追踪。盯采购信号比盯招聘 JD 更早看到需求。
证据：[北京银行中标公告](../data/signals/2026-08-13-bank-of-beijing-llm-security-gateway.yml)（A 级）、[采购记录 CSV](../data/procurement/2026-08.csv)
